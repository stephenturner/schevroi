# Virginia Degree ROI Explorer

View live: **[stephenturner.github.io/schevroi](https://stephenturner.github.io/schevroi)**

A static page for comparing SCHEV's return on investment estimates for bachelor's programs at Virginia colleges. You can line up one program across schools or see all of one school's programs at once.

The figures come from the [SCHEV College Outcomes ROI dashboard](https://collegeoutcomes.schev.edu/rdPage.aspx?rdReport=ROI.ROI_Dashboard), copied in October 2026. This project is not affiliated with SCHEV. [data/README.md](data/README.md) describes the columns and the method's limits.

To run it locally, serve the repo folder and open http://localhost:8000:

```sh
python3 -m http.server
```
